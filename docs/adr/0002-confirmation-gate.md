# ADR-0002：业务副作用必须经过确认或显式授权门禁

- 状态：Accepted
- 日期：2026-08-12

## 背景

自然语言理解和 LLM 输出存在歧义，邮件、转发内容和 RAG 片段也可能包含恶意指令。错误修改内部日程或发送非预期消息会直接损害用户信任。

## 决策

日程变更和消息发送等业务副作用由 Actions/Reminders 门禁执行。默认只有用户确认的、仍有效的具体 Proposal 版本可以生成日程 ActionRequest；由已确认日程派生的到期提醒视为同时获得有限授权。所有执行必须幂等并可审计。

## 结果

- Connector、Understanding、Scheduling 都不能直接写外部系统。
- 自动化规则未来必须作为显式、有限范围的确认策略扩展。
- 交互可能多一步，但优先换取安全和信任。
